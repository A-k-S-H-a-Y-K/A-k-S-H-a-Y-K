## 🚀 What I've built

### ⚡ [Mini Inference Engine](https://github.com/A-k-S-H-a-Y-K/mini-inference-engine)
**A vLLM-style LLM serving engine, written from scratch in PyTorch.**
Continuous batching · paged KV cache · prefix caching · CUDA graphs

> 🏎️ **75–83% of vLLM's throughput** on a T4 · 📦 **3.6× more requests** in the same memory · ✅ token-identical to Hugging Face

### 🛡️ [Fed-MediShield](https://github.com/A-k-S-H-a-Y-K/Fed-MediShield)
**Catching hospitals that secretly poison a shared AI model.**
A defence against backdoor attacks in federated intrusion detection for medical IoT.

> 🎯 Attack success **99% → 0.17%** · 🥇 the only one of **9 methods** that removed the backdoor and kept accuracy · 📄 research paper

### 🧠 [Memory Assistant](https://github.com/A-k-S-H-a-Y-K/memory-assistant) · [**try it live →**](https://memory-assistant-pf1w.onrender.com)
**Ask your own notes anything, and get answers with citations.**
Hybrid search · cross-encoder reranking · follow-up questions

> 🔍 Look-alike questions rejected **10% → 75%** · 📊 102-question held-out test set · 🚫 0 made-up answers
